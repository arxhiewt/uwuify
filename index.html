Getting started

  1. Add uwuify to your Discord server
  2. Run /uwuify as an administrator or with a whitelisted role.
  3. That’s it!

uwuify only transforms messages in one channel at a time. To change the current channel, use /webhook.

Commands

/uwuifyAdmin or whitelisted role

Turns a member’s messages into uwu speak.

/webhookAdmin

Changes the channel where messages are transformed.

/intensityAdmin

Changes the strength of the transformation.

/hidecommandAdmin

Hides the command from other members.

/whitelist viewAdmin

Shows the roles allowed to use /uwuify.

/whitelist addAdmin

Allows a role to use /uwuify.

/whitelist removeAdmin

Removes a role’s access to /uwuify.

Type a command in Discord, then choose its options.

Limits per server

  • 1 webhook
  • 5 members uwuified at once
  • 3 whitelisted roles

Permissions

The bot needs these permissions to read, replace, and repost messages in the active channel:

View Channels
Access the channel where uwuify runs.
Send Messages
Post transformed messages.
Read Message History
Access messages in the channel.
Manage Messages
Delete original messages so they can be replaced.
Manage Webhooks
Create and manage the webhook used to repost messages.
Create Instant Invite is optional.

If enabled, the bot saves a server invite the developer can use to join for support. Turn it off when adding the bot, or remove it in Server Settings → Roles. The bot works without it.

If a webhook is blocked or deleted, check the channel’s permissions or ask in the support server.

Privacy policy

Policy updated October 2026

What the bot stores

Your server ID, its webhook ID, and a server invite link if you grant Create Instant Invite. Only the developer can access these, to operate and support the bot.

What happens to messages

Messages are transformed in memory and discarded after reposting. Message content isn’t logged or saved to a database. No AI is involved. Usernames and user IDs aren’t stored.

Removing your data

Remove uwuify from your server to delete its stored server ID, webhook ID, and invite link.

Sharing and contact

Stored data isn’t sold or shared with third parties. For questions about your data, join the support server and open a thread.
