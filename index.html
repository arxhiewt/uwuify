How it works

Add it. Run one command. Done.

No setup screen, no config file, nothing to configure first.

01

Add uwuify to your server

Invite the bot and accept the permissions it asks for.

02

Run /uwuify on someone

Pick a member. Their messages start getting transformed right away.

03

Move it anytime

Want it in a different channel? Run /webhook to move it there.

!

Webhook getting blocked or deleted? Give uwuify Administrator, or kick it and add it back to your server.

Limits

What uwuify can handle right now

These are the current limits. They may change as uwuify grows.

1

Uwuification channel per server

uwuify only transforms messages in one channel at a time. Move it with /webhook.

5

Concurrent uwufications per server

Up to 5 members can be uwuified at once, all in that one channel.

1

Supported whitelist role

Only one role can be whitelisted to use /uwuify at a time.

Commands

Every command uwuify has

/uwuify <user>Admin or whitelisted role

It's the bot. You should know what it does.

e.g. /uwuify @CoolEthan133

/webhook <#channel>Administrator

Moves the transformation channel. Only one channel per server can be active at a time.

e.g. /webhook #general

/intensityAdministrator

Sets how strong the uwu transformation is.

/hidecommandAdministrator

Hides the command so people don't know you ran it.

/whitelist <role>Administrator

Lets a chosen role use /uwuify. Every other command stays Administrator only.

e.g. /whitelist @Mods

/helpAll members

Shows command info, i guess.

Privacy Policy & Terms

Last updated: August 2026

Privacy Policy

1. What we collect

When your server invites uwuify, we store three things: your server's ID, the webhook ID created by the /webhook command, and — only if the "Create Instant Invite" permission is granted at invite time — a standing invite link to your server. All three are visible only to the bot's developer and are used solely to run and support the bot.

2. What we never collect

uwuify uses zero AI. Message content is never read by a language model, never logged, and never written to a database — it's transformed in memory and discarded the instant it's reposted. We also never store usernames, user IDs, or any other personal data.

3. Why we keep an invite link

A saved invite link lets the developer join your server directly if support is ever needed, e.g. to fix a broken webhook. If you ever see the developer show up in your server, that's what's happening — they've used the invite your server generated.

4. Keeping your server private

If you'd rather not generate a standing invite, untick Create Instant Invite when adding uwuify (or remove it afterwards in Server Settings → Roles). uwuify works exactly the same either way — this permission only affects the developer's ability to rejoin later.

5. Removing your data

Kick uwuify from your server at any time to delete its stored server ID, webhook ID, and invite link.

6. Third parties

uwuify doesn't sell or share data with anyone. What's stored is used exclusively to operate the bot.

7. Contact

Questions? Join our support server and open a thread, or message the developer directly on Discord.
